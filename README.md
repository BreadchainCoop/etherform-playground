# etherform-playground

A scratch repository for exercising [etherform](https://github.com/BreadchainCoop/etherform) — its reusable workflows, release tooling, upgrade-safety checks, and CI/CD integration — against a throwaway Foundry project.

Nothing here is meant to be deployed or used in production. Contracts and scripts exist only to give the etherform workflows something to chew on.
